Microsserviços

7 serviços independentes

Cada serviço tem seu próprio repositório, banco de dados, pipeline CI/CD e manifestos Kubernetes. Comunicam-se via eventos assíncronos (RabbitMQ) e HTTP síncrono (via BFF).

BFF + Frontend
.NET 10 · React + Vite · TypeScript
Ponto de entrada único. Proxy reverso para os 6 serviços downstream, validação JWT, serve o SPA React. Build multi-stage Docker (Node 20 → .NET 10).
Ingress ALB JWT Guard
Auth Service
.NET 8 · AWS Lambda · SQL Server RDS
Autenticação e autorização. Emite tokens JWT (HS256). Único serviço com banco SQL relacional. Deploy como Lambda via AddAWSLambdaHosting.
SQL Server RDS Lambda
OS Service
.NET 10 · Clean Architecture · MongoDB
Ponto de entrada da Saga. Gerencia o ciclo de vida das Ordens de Serviço: Recebida → EmDiagnóstico → AguardandoAprovação → EmExecução → Finalizada → Entregue.
MongoDB Saga entry K8s + ECS
Billing Service
.NET 10 · Clean Architecture · MongoDB
Orçamentos e pagamentos via MercadoPago PIX. Recebe os.diagnostico.registrado, cria orçamento, aguarda aprovação do cliente e confirma pagamento.
MongoDB MercadoPago PIX
Cadastro Service
.NET 10 · Clean Architecture · MongoDB
Gestão de Clientes, Produtos e Categorias. Dados de referência utilizados pelos demais serviços. CRUD completo com paginação.
MongoDB K8s + ECS
Estoque Service
.NET 10 · Clean Architecture · MongoDB
Controle de itens e reservas. Ouve os.aberta para reservar peças, libera ao cancelar. Ajuste manual de estoque com histórico.
MongoDB Reservas
Execução Service
.NET 10 · Clean Architecture · MongoDB
Execução técnica das OSs com etapas granulares. Ouve pagamento.confirmado para iniciar. Publica execucao.finalizada ao concluir o reparo.
MongoDB Saga end

Saga Pattern

Coreografia via RabbitMQ

Escolhemos Coreografia (sem orquestrador central) para garantir desacoplamento total e eliminar ponto único de falha. Cada serviço conhece apenas os eventos que deve publicar e consumir.

Fluxo feliz

1
os.aberta
Cliente abre OS → OS Service publica evento.
Estoque reserva peças
2
os.diagnostico.registrado
Mecânico registra diagnóstico com valor estimado.
Billing cria orçamento
3
pagamento.confirmado
Cliente aprova orçamento e paga via PIX.
OS → EmExecução Execução inicia
4
execucao.finalizada
Mecânico conclui o reparo com valor final.
OS → Finalizada
5
os.entregue
Veículo entregue ao cliente. Saga concluída.

Compensação (rollback)

C1
pagamento.falhou
Pagamento rejeitado pelo MercadoPago.
OS → Cancelada Estoque libera peças
C2
os.cancelada
Cliente solicita cancelamento após diagnóstico.
Billing estorna Estoque libera
DLQ
Dead Letter Queue
Cada fila tem DLQ dedicada. Mensagens não processadas após 3 tentativas são retidas para análise e reprocessamento manual.

Matriz de Eventos

Routing Key Publicado por Consumido por Ação desencadeada
os.aberta OS Estoque Reserva peças para a OS
os.diagnostico.registrado OS Billing Cria orçamento com valor estimado
pagamento.confirmado Billing OS, Execução OS muda para EmExecução; Execução inicia etapas
pagamento.falhou Billing OS, Estoque OS cancela; Estoque libera reserva
execucao.finalizada Execução OS OS muda para Finalizada com valor final
os.cancelada OS Billing, Estoque Billing estorna; Estoque libera peças
os.entregue OS — Fim da Saga — veículo entregue

Stack Técnica

Tecnologias utilizadas

Escolhas feitas com foco em requisitos do curso, escalabilidade e aderência a boas práticas de microsserviços.

⚙️

.NET 10 + Clean Architecture

5 camadas: Domain, Shared, Application, Infra, API. Inversão de dependência em todos os serviços .NET 10. Auth usa .NET 8 + Lambda.

🐇

RabbitMQ 3.13

Exchange topic tech.saga para coreografia. Uma DLQ dedicada por fila. MassTransit como abstração de consumo.

🍃

MongoDB 7.0

NoSQL para OS, Billing, Cadastro, Estoque e Execução. Document Model com histórico de status embutido por documento.

🗄️

SQL Server RDS

Banco relacional para Auth Service — cumpre o requisito de banco SQL do curso. Entity Framework Core com Migrations.

☁️

AWS ECS Fargate + EKS

Deploy primário em ECS Fargate (serverless containers). Manifestos Kubernetes (K8s) com HPA para escalonamento automático.

⚡

AWS Lambda

Auth Service roda como Lambda via AddAWSLambdaHosting. Cold start mínimo com .NET Native AOT-ready.

💳

MercadoPago PIX

Integração de pagamento via PIX no Billing Service. Webhook para confirmação assíncrona de pagamento.

📊

Datadog StatsD

Métricas de observabilidade via IMetricsService / DatadogMetricsService. Contadores por operação e por status de OS.

🏗️

Terraform

Infraestrutura como código. Backend S3 por serviço. Provisiona ECS, ECR, RDS, Load Balancers, Security Groups.

TRIGGERS
deploy.yml + infra.yml + quality.yml disparam em push main. k8s-deploy.yml é manual via workflow_dispatch com input image_tag.
PATH FILTERS
deploy.yml só dispara em mudanças em src/ ou Dockerfile. infra.yml em infra/. Evita deploys desnecessários.
SECRETS
AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN (Academy, 4h), SONAR_TOKEN, variáveis de banco e JWT.
